# Raw data (not included)

Copy the two training folders of the PhysioNet/CinC Challenge 2019 data here:

```
data/raw/
  training_setA/    (.psv files, sub-folders are fine)
  training_setB/
```

Source: https://physionet.org/content/challenge-2019/1.0.0/ (see the license that ships with the dataset).

The data is not committed: it is ~40,000 files, and GitHub rejects any file over 100 MB.
